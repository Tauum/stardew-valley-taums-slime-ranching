# Stage 7 — All planned slime types and abilities

Base roles: Red Fighter; Yellow Revealer; Blue Irrigator; Green Collector (includes pocket inventory); Orange Nurturer; Violet Prospector; Pink Healer. Six wheel tertiary hybrids inherit paired abilities: Red-Orange, Orange-Yellow, Yellow-Green, Green-Blue, Blue-Violet, Violet-Red. Exact Pink hybrid recipes remain open.

Exceptional: Black grants one extra nighttime hour; White grants one extra morning hour; Golden capped shop discounts; Prismatic rideable mount plus Adaptation (temporarily adopts a base ability). Shadow Clone is a rare mutation/trait; copies are limited and cannot breed or recursively clone. Void Pocket Storage is merged into Collector, not a separate type. Shiny status remains independent. Exceptional color acquisition rules still need balancing.

All types are **core scope**, even though ability implementations come late. Time mechanics require special care around day transitions, events and saving; single-player first.

**Done when:** each ability and hybrid combination has automated/manual tests and an in-game visual.
