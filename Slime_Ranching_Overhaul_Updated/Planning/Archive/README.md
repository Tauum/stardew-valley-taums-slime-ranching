# Historical design archive

The active source for design and implementation is [DEVELOPMENT_NOTES_2.0.md](../DEVELOPMENT_NOTES_2.0.md). Do not treat archived files as current requirements. They are retained as historical source material; use Git history for provenance and consult these files only when the active notes identify a gap or ask for historical context.

## Archive contents

- `Source/slime_daycare_story_and_development_notes_v7.md` is the original v7 design source. It contains superseded proposals and rationale as well as design context. The 2.0 notes map its major sections and state which decisions supersede them.
- `Legacy-Reference/Features/` contains earlier feature specifications.
- `Legacy-Reference/Stages/` contains the old 1.x implementation stages.
- `Legacy-Reference/Technical/` contains prior architecture, lifecycle, implementation, and test specifications.
- `Legacy-Reference/Planning/` contains old 1.x checklists, handoffs, decisions, roadmaps, task breakdowns, and temporary test values.
- `Source/CHAT_REFERENCE.txt` links to the original design discussion; it is a reference link, not a specification.

The [player guide](../../Guides/PLAYER_GUIDE.md) and [testing records](../COMPLETED_FEATURE_TESTS.md) remain outside the archive because they serve player support and 1.x test history, not 2.0 design.
