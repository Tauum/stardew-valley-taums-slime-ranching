# Stage 5 — Advanced machines

- Mutagenic Pool: expensive Slime resource input, adult slime mutation attempts, nonlethal failures, **per-slime** escalating pity chance; keep original genome properties unless mutation changes them explicitly.
- Chromatic Crystals: consumable inserts into breeder, select guaranteed pure base color, not a furniture object; cannot force hybrid/Golden/Prismatic.
- Gel Refinery: bank Slime and convert existing vanilla items (Stone → Clay, Copper Ore → Iron Ore, Broken Glasses → Refined Quartz, Mixed Seeds → seasonal seeds) at balanced resource costs.
- Cosmetic transmutation is deferred beyond v1.

**Done when:** resource accounting, item conversion, persistence and failure recovery tested.
