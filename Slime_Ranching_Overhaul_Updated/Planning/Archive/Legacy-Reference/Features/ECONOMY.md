# Existing-item production and economy

Slimes can produce existing Stardew Valley items rather than new loot categories.

| Species | Candidate outputs (proposed) |
|---|---|
| Green | Fiber, Sap |
| Blue | Seaweed, Green Algae |
| Red | Coal, Copper Ore |
| Yellow | Clay, Mixed Seeds |
| Orange | Hardwood, Wood |
| Violet | Iron Ore, rare Gold Ore |
| Pink | Wild Seeds, extremely rare Life Elixir |

Hybrids draw from both base pools. Size influences amount; shiny mildly improves output. Exceptional species need separately balanced tables. All rates, caps and loot probabilities are TBD. Beware high-value farming loops and avoid replacing vanilla progression. Gel Refinery recipes are in `MACHINES_AND_REFINERY.md`.
